# Moon Tools Hub

Moon Tools Hub is a free collection of 14 tools that run entirely in your browser. Launched in October 2026, the site is based in Pakistan. No sign-up, no uploads — your files never leave your device.

Website: https://moontoolshub.com

## Image tools

- [Image Compressor](https://moontoolshub.com/image-tools/image-compressor) — shrink image file sizes without losing quality
- [Image Resizer](https://moontoolshub.com/image-tools/image-resizer) — resize images to the dimensions you need
- [JPG to WebP Converter](https://moontoolshub.com/image-tools/jpg-to-webp) — convert JPG images to WebP
- [WebP to PNG Converter](https://moontoolshub.com/image-tools/webp-to-png) — convert WebP images to PNG

## PDF tools

- [PDF Merge](https://moontoolshub.com/pdf-tools/pdf-merge) — combine multiple PDF files into one
- [PDF Split](https://moontoolshub.com/pdf-tools/pdf-split) — split a PDF into separate pages or files
- [PDF Compressor](https://moontoolshub.com/pdf-tools/pdf-compressor) — reduce the size of PDF files
- [PDF to JPG](https://moontoolshub.com/pdf-tools/pdf-to-jpg) — convert PDF pages to JPG images
- [Image to PDF](https://moontoolshub.com/pdf-tools/image-to-pdf) — turn images into a PDF document

## Productivity tools

- [Password Generator](https://moontoolshub.com/productivity-tools/password-generator) — create strong, random passwords
- [Text Difference Checker](https://moontoolshub.com/productivity-tools/text-difference-checker) — compare two texts and spot the differences
- [Text File Maker](https://moontoolshub.com/productivity-tools/text-file-maker) — write text and download it as a file
- [Typing Skill Test](https://moontoolshub.com/productivity-tools/typing-skill-test) — test and practise your typing speed
- [Text to Speech Converter](https://moontoolshub.com/productivity-tools/text-to-speech) — hear written text read aloud

## How it works

Everything runs locally in your browser. There is nothing to install and no account to create, and your files are never uploaded anywhere.
